# CTA and WhatsApp Flow

The first website should use WhatsApp and email as the main enquiry channels.

## 1. Primary CTA Hierarchy

Primary:

- Request a Quote

Secondary:

- Chat on WhatsApp

Service-specific:

- Send Research Requirements
- Discuss a Business Project
- Ask About Website Care
- Book a Consultation

Avoid vague CTAs:

- Get Started
- Learn More
- Unlock Growth
- Transform Now
