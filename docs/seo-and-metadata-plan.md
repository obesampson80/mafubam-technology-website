# SEO and Metadata Plan

This plan supports a static website. It does not require a backend.

## 1. Primary SEO Strategy

MAFUBAM should target clear service and location intent instead of broad generic keywords.

Primary themes:

- Port Harcourt digital services
- Research data analysis support
- Academic document formatting Nigeria
- Website design Port Harcourt
- Business website development Nigeria
- Technical diagrams and research visuals
- Website maintenance for small businesses

Do not keyword-stuff. Use natural service language.
