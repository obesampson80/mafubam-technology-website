- Founder name for public use

- Phone number

- Brand colors

- Data analysis description
- Document formatting description
- Technical diagrams description
- Presentation design description
- Programming support description

Business Technology Solutions:

- Website development description

## 4. Packages and Pricing

Needed:

- Starting prices or "from quote" language
- What each package includes
- What each package excludes
- Revision policy
- Urgency policy
- Deposit/payment policy
- Delivery expectations

## 5. Portfolio Content

Prepare at least six samples:

- Two research or technical diagrams
- One formatted document sample
- One data-analysis dashboard or results presentation
- One business website sample
- One website redesign concept

For each sample:

- Project type
- Problem
- Service provided
- Result
- Permission status
- Whether it must be anonymised
- Whether it is real client work, anonymised work, sample work or concept work

- How to request a quote

## 8. Launch Readiness

- Domain selected
- Hosting selected
- Email configured
- WhatsApp Business configured
- Google Business Profile planned
- Analytics plan chosen
- Search Console planned
- Portfolio samples ready
- First month content topics drafted

## 9. Anti-Generic Content Requirements

Before coding, collect:

- 5 real client questions or common enquiry messages.
- 3 short founder notes about how work is handled.
- 3 examples of projects MAFUBAM can describe honestly.
- 3 examples of work MAFUBAM will refuse on ethical grounds.
- A plain-language explanation of the quote and deposit process.
- A list of actual tools used for research, documents, diagrams, websites and data analysis.
- A list of actual file formats accepted and delivered.
