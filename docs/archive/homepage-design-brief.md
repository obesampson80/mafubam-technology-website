# Homepage Design Brief

This is the implementation-ready brief for the homepage design.

## 1. Homepage Objective

Within 10 seconds, visitors should understand:

- MAFUBAM Technology provides digital solutions for research and business.
- It is based in Port Harcourt and serves clients remotely.
- It is a registered company.
- They can choose Research Solutions or Business Technology Solutions.
- They can request a quote or chat on WhatsApp.

## 2. First Viewport Requirements

Required content:

- Brand: MAFUBAM Technology
- Eyebrow: Registered technology company in Port Harcourt
- H1: Digital Solutions for Research and Business
- Short supporting copy
- Primary CTA: Request a Quote
- Secondary CTA: Chat on WhatsApp
- Trust line: MAFUBAM TECHNOLOGY LTD | CAC RC 7522288 | Port Harcourt
- Hero proof image: `hero-proof-workbench-v2@2x.png`

Layout:

- Desktop: copy and CTA on one side, proof visual on the other or slightly below depending on available width.
- Mobile: copy first, CTAs next, trust line, then proof visual.

## 3. Emotional Target

The first screen should feel:

- Competent
- Real
- Calm
- Human
- Professional
- Useful

It should not feel:

- Generic
- Flashy
- Overly academic
- Overly corporate
- Like a SaaS dashboard
- Like an assignment-writing service

## 4. Section Order

Recommended homepage order:

1. Hero
2. Research / Business path split
3. Featured services
4. How it works
5. Proof / portfolio preview
6. Why MAFUBAM
7. FAQ
8. Final CTA
9. Footer

## 5. Research / Business Path Split

Purpose:

- Prevent mixed messaging.
- Let each visitor self-select.

Design:

- Two large path panels.
- Equal visual weight.
- Research panel should show chart/document/diagram cues.
- Business panel should show website/dashboard/document cues.

Content:

Research:

Data analysis, formatting, diagrams, presentations and programming support.

Business:

Websites, maintenance, digital forms, documents and practical IT support.

## 6. Featured Services

Use six compact entries:

- Data Analysis
- Document Formatting
- Technical Diagrams
- Presentation Design
- Website Development
- Website Care / IT Support

Each entry should include:

- One-line outcome
- Service category
- CTA or link to relevant page

## 7. How It Works

Use six steps:

1. Send project details
2. Requirements are reviewed
3. Written quote is issued
4. Deposit confirms the project
5. Draft or preview is reviewed
6. Final files are released after balance payment

Design:

- Horizontal timeline on desktop.
- Stacked steps on mobile.
- Keep it compact.

## 8. Proof / Portfolio Preview

Use three to four proof cards:

- Technical Diagram and Architecture Design
- Data Visualisation and Result Presentation
- Dashboard / Report Interface
- Presentation and Document Support

Each card:

- Visual thumbnail
- Category label
- One-sentence result
- Confidentiality note if needed

## 9. FAQ Preview

Use 5-7 questions:

- How much will this cost?
- What files should I send?
- Do you work remotely?
- Can you help with data analysis?
- Can you build a business website?
- What academic work do you refuse?
- How do revisions work?

## 10. Mobile-Specific Rules

Mobile is the primary experience.

Rules:

- CTAs must be visible before excessive scrolling.
- Buttons should stack cleanly.
- Hero image must not push service paths too far down.
- WhatsApp access should be visible but not cover content.
- Text should stay concise.
- Avoid large decorative spacing.

## 11. Dark Mode Homepage Treatment

If dark mode is implemented:

- Hero section can use dark navy background.
- Hero proof image stays light and framed.
- Research/business path cards can be dark raised surfaces.
- CTA buttons should retain strong contrast.
- FAQ and long reading sections may use light surfaces if that improves readability.

## 12. Homepage Approval Test

Before coding or shipping, check:

- Can a visitor explain what MAFUBAM does after 10 seconds?
- Are Research and Business paths obvious?
- Is the site credible without reading the About page?
- Is the proof visual visible and relevant?
- Is WhatsApp easy to find?
- Does the page feel specific to MAFUBAM?
- Does it avoid generic AI agency language?
- Does it work naturally on mobile?
