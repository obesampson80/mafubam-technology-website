## 3. Portfolio Asset Rules

Each asset must be labelled as one of:

- Real client work, public with permission
- Real client work, anonymised
- Demonstration sample
- Concept redesign

Never imply sample or concept work is a real paid client project.

## 4. Image Style

Use:

- Clear screenshots
- Clean crops
- Light annotations
- Real work surfaces if available
- Legible charts and diagrams

Avoid:

- Blurred screenshots
- Tiny unreadable previews
- Fake app dashboards
- Abstract AI-generated office scenes
- Random stock laptops

## 5. Asset Sizes To Prepare Later

Approximate targets:

- Logo SVG or high-resolution PNG
- Favicon SVG/PNG
- Social preview: 1200 x 630
- Hero workbench: responsive composition, source images at least 1200px wide where possible
- Portfolio thumbnails: consistent aspect ratio, preferably 4:3 or 16:10
- Founder photo: square or 4:5 crop

## 6. Confidentiality Checklist

Before using any screenshot or document:

- Remove names, phone numbers, emails and student IDs unless permission is explicit.
- Remove school/client identifiers where needed.
- Replace sensitive data with dummy values.
- Avoid exposing raw datasets.
- Use sample data for charts if real data is confidential.
- Label anonymised samples clearly.
- Avoid displaying Turnitin or academic submission evidence in a way that identifies the client or institution.
