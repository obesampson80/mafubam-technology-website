# Information Architecture

## 1. Recommended Sitemap

Version 1 should be small, clear and static.

Pages:

- Home
- Research Solutions
- Business Technology Solutions
- Portfolio
- Packages
- About
- Contact
- Request a Quote
- Privacy Policy
- Terms of Service

Optional later pages:

- Data Analysis
- Document Formatting
- Website Design
- Website Care Plan
- Case Study detail pages
- Blog or Insights

## 5. Portfolio Page

Portfolio items should use a consistent structure:

- Project type
- Problem
- Service provided
- Approach
- Result
- Visual evidence
- Confidentiality note if anonymised

Initial portfolio targets:

- 2 technical diagrams
- 1 formatted document sample
- 1 data-analysis dashboard or result presentation
- 1 business website sample
- 1 website redesign concept

## 6. Request a Quote Page

For version 1, this can be a static page with a structured form UI or a WhatsApp/email handoff.

Fields to collect:

- Name
- Organisation or school
- Phone or WhatsApp
- Email
- Service category
- Project description
- Deadline
- Budget range
- Existing files available
- Preferred contact method

If no backend is used, the page can offer:

- WhatsApp prefilled message
- Email template
- Link to Google Forms, Tally, Formspree or another form service
