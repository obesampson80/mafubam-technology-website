# UI System Brief

This is a design-system planning note, not code.

## 1. Overall UI Feel

The interface should feel:

- Professional
- Calm
- Practical
- Evidence-led
- Local-aware
- Modern without looking like a SaaS template
- Suitable for Nigerian mobile users, research clients and local business owners

## 2. Layout System

Use:

- Mobile-first sections
- Max-width content containers
- Alternating full-width bands where useful
- Compact service cards
- Large but not oversized hero type
- Clear spacing between unrelated content

Avoid:

- Cards inside cards
- Overly decorative grids
- Large empty hero areas
- Repeating identical card sections

## 3. Navigation

Desktop:

- Logo left
- Main nav center or right
- Quote CTA on the right

Mobile:

- Logo
- Menu button
- Visible WhatsApp or quote shortcut where space allows

Required nav items:

- Research
- Business
- Portfolio
- Packages
- About
- Contact

## 4. Buttons

Primary:

- Request a Quote
- Dark or strong accent background

Secondary:

- Chat on WhatsApp
- Outline or lighter treatment

Service buttons:

- View Research Services
- Explore Business Solutions
- Send Research Requirements
- Discuss a Business Project

Rules:

- Do not use vague "Learn More" as the main CTA.
- Touch targets must be comfortable on mobile.
- Button text must not wrap awkwardly.

## 5. Cards

Use cards for:

- Service summaries
- Portfolio items
- Package summaries
- FAQ blocks if needed

Rules:

- Keep border radius modest.
- Keep card content specific.
- Do not make every section a floating card.
- Avoid nested cards.

## 6. Forms and Quote UI

Version 1 does not need a backend.

The quote page can show:

- A visible requirements checklist
- WhatsApp prefilled message button
- Email template guidance
- Optional third-party form later

If a form UI is designed:

- Use labels, not placeholder-only fields.
- Group related fields.
- Mark optional fields clearly.
- Do not request sensitive file uploads on an insecure static form.

## 7. Color Use

Use the palette to create hierarchy:

- Navy for structure and trust
- Teal/cyan for actions and highlights
- Green only for positive status/WhatsApp-related cues
- Amber sparingly for notes or reminders
- Neutral backgrounds for readability

Avoid one-note blue/purple pages.

## 8. Theme and Dark Mode

Recommended:

- Light-first website with dark-mode support or carefully placed dark sections.
- Dark mode should use navy/charcoal surfaces, light text and restrained teal accents.
- Bright proof visuals should remain bright and be framed with a border/shadow.

Avoid:

- Inverting proof images.
- Pure black pages with low contrast grey text.
- Neon cyberpunk or crypto-style styling.
- Dark mode that makes charts, documents or forms harder to read.

## 9. Accessibility

Required:

- Visible keyboard focus
- Strong contrast
- Consistent navigation
- Descriptive links
- Large touch targets
- Reduced motion preference respected later if animation is added
